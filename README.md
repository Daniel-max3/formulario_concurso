# Formulario de Inscrição para Concurso

## Projeto desenvolvimento em Python

Este programa simula uma incrição para concurso público.

## Funcionalidades

- Cadastro do Candidato;
- Validação de idade;
- Escolha de escolaridade;
- Escolha da área profissional;
- Uso de comandos condicionais

## Tecnologias utilizadas

- Python 3
- vs Code
- Git
- GitHub
